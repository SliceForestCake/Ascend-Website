# 🧗 Ascend Bouldering Gym Website

> A modern, responsive front-end website for a fictional bouldering gym, **Ascend**, developed as part of a Web Fundamentals assignment. The project showcases the use of HTML5, CSS3, and JavaScript to create an engaging, interactive user experience with smooth animations, intuitive navigation, and robust client-side functionality.

---

## 📌 Features & Pages

* **Home Page:** Modern landing page featuring smooth scrolling, animated transitions, an earth-tone color palette inspired by natural climbing environments, and a functional embedded Google Maps location.
* **First-Timer Guide:** Dedicated page introducing new climbers to basic bouldering concepts, etiquette, and what to expect on their first visit.
* **Pricing:** Clear, organized membership and day-pass pricing cards designed for readability and quick comparison.
* **Meet Our Staff:** Profile card layout introducing the gym's expert staff members with a fully responsive design.
* **Contact Us:** Interactive contact form featuring client-side validation for user input and feedback messages.
* **User Authentication:** Functional Sign-Up and Sign-In system built with JavaScript, including real-time input validation, error checking, and prevention of incomplete submissions.

---

## 🛠️ Technologies Used

* **HTML5:** Semantic document structure and markup
* **CSS3:** Custom styling, responsive flexbox/grid layouts, smooth transitions, and UI animations
* **JavaScript (ES6):** Interactive UI functionality, form validation logic, and authentication simulation
* **Google Maps Embed API:** Interactive gym location integration

## 🚀 Getting Started & Usage

Because this is a static front-end web project, no complex server setup or package installation is required to view it.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/ascend-bouldering-gym.git
   cd Ascend
   ```

2. **Open the project:**
   * Open `index.html` directly in any modern web browser, **or**
   * Use a local development server (such as the **Live Server** extension in Visual Studio Code) for the best interactive experience.
